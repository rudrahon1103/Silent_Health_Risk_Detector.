About Silent Health AI

An AI-based health risk screening system designed to demonstrate how Machine Learning can be integrated into a web-based healthcare application.

What is Silent Health AI?

Silent Health AI is a multi-disease Machine Learning project that estimates the risk of selected health conditions using user-provided health parameters.

The system combines trained Machine Learning models with a Flask web application to provide a simple and accessible health-risk screening interface.

Diseases Covered

🌸 PCOS

Risk screening using clinical and lifestyle parameters.

🩸 Anemia

Risk estimation using blood-related parameters.

🧪 Diabetes

Risk screening using common clinical measurements.

🦋 Thyroid Disease

Risk estimation using thyroid and health parameters.

🧠 Stroke

Risk screening using demographic and health factors.

How the System Works

01

Enter Parameters

The user provides the required health information.

02

AI Analysis

The selected trained Machine Learning model processes the input.

03

Risk Prediction

The system displays the estimated risk result.

Technology Used

Python Machine Learning Scikit-learn Flask HTML CSS Joblib Jupyter Notebook

Important Disclaimer

Silent Health AI is developed for educational and research purposes. The predictions generated by this system are risk estimations based on trained Machine Learning models and should not be considered a medical diagnosis or a substitute for professional medical advice.
